# Master Prompt — YouTube Jazz SEO

Use the video's verified music metadata, episode concept, thumbnail story and supplied keyword evidence to write concise English YouTube metadata.

## Source hierarchy

Use evidence in this order:

1. vidIQ;
2. YouTube search autocomplete;
3. Google Trends.

Apply semantic relevance before metrics. Never select a keyword solely because it has high volume. Exclude keywords that imply a different genre, instrument, setting, season, entity or listening purpose than the video actually delivers.

## Fixed channel hierarchy

- Main genre and default primary keyword: `vintage jazz`.
- Recurring secondary branch: `late night jazz`.
- Conditional secondary branch: `jazz noir`, only for genuinely noir audio and episodes.

Do not change the main genre merely because another keyword has higher current volume. SEO supports the chosen channel identity; it does not redefine the music from video to video.

## Title target

```text
vintage jazz — [emotional or immersive world-building sentence]
```

Write the entire title in lowercase. Put `vintage jazz` at the beginning by default. The hook may be immersive second person, a cinematic scene, a memory, a quiet emotional line or an unfinished story. It must include a natural time anchor and a direct or indirect maritime anchor. Add `late night jazz` or `jazz noir` only when it remains natural and the branch is verified. Use no more than 100 characters and avoid formulaic repetition, keyword stuffing, clickbait, emojis and unsupported claims.

## Description target

Start the first sentence naturally with `Vintage jazz`. Follow with only 1–3 concise sentences describing the scene, emotional tone and appropriate listening context. Add secondary phrases only when they read naturally. Do not turn the description into a keyword list.

## Channel fit

The channel universe is slow, intimate, mature Vintage Jazz built around Popeye's mid-century sailor world: warm old interiors, analog character, old memories, quiet solitude and occasional distant maritime atmosphere. The default branch is late-night, slightly bittersweet and comforting. Jazz Noir is a secondary branch, not the whole channel.

Treat these as conditional:

- `jazz noir` or `dark jazz`: only for genuinely noir/dark episodes;
- `jazz piano`, `jazz saxophone` or other instrument keywords: only when that instrument is prominent across the video;
- `jazz rain`, `jazz cafe`, `jazz lounge`, `smooth jazz`, study/sleep/relax cues: only when supported by the actual mix and presentation.

When evidence is incomplete, choose a broad truthful core keyword and list the missing research rather than inventing metrics.
